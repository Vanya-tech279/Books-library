📚 Book Library App

A simple and modern Book Library web application built using React (Vite), Redux Toolkit, React Router, and JSON Server API.
This project allows users to browse books, view details, search, filter by category, and add new books dynamically.

🚀 Features
📖 Home page with categories and popular books
📚 Browse books with dynamic API data
🔍 Search books by title or author
🏷️ Filter books by category
📄 Book details page (dynamic routing)
➕ Add new books (POST API)
🖼️ Book cards with cover images
⚡ Redux Toolkit state management
🌐 JSON Server as backend API
🎨 Responsive and modern UI design
❌ 404 Page for invalid routes
🛠️ Tech Stack
React (Vite)
Redux Toolkit
React Router DOM
JSON Server (Fake REST API)
JavaScript (ES6+)
CSS3
